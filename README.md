# Kategoriziranje (prepoznavanje) hrvatskoga teksta

Repozitorij sadrži model za prepoznavanje i katagoriziranje hrvatskoga jezika.

Model je generiran iz rječnika dostupnoga na [`https://github.com/krunose/hunspell-hr`](https://github.com/krunose/hunspell-hr) naredbom (i alatom) `createfp < hr_HR.dic > hr.lm`. Iz rječnika su se uklonile oznake klasa i posebnih znakova.

Plan je bio napraviti model iz datoteke [`wordlist`](https://github.com/krunose/hunspell-hr/tree/master/tools) no ne posjedujemo dovoljno snažno računalo da proces završi u razumnom roku.
